# 八字综合判读方法论

## 证据顺序

报告中的每个观点都按以下链条写，不能从符号直接跳到断语：

1. **算出**：引用脚本输出的四柱、十神、藏干、关系、大运或流年原值。
2. **依据**：说明历法规则或生克、阴阳、位置、阶段等判断标准。
3. **结论**：写成“可供判读”的倾向，给用户可核验的现实表现，再给行动建议。

确定性字段只能引用 `calculation`；若 `alternateCalculation` 不为 `null`，另一换日派只能引用该对象，不得重新心算。没有证据时写“不足以判断”。

## 综合观察

- 以日干为观察原点。年、月、日、时柱分别观察初始环境、社会定位、核心自我与长期产出；年龄段只作方法论视角，不当作事件必然发生的边界。
- 先看月令、透干、通根和全局生克制化，再看五行统计。明八字与藏干计数只是组成清单，没有季节和权重，不能直接推出旺衰。
- 十神解释必须双向：印是支持也可能形成依赖；食伤是产出也消耗精力；官杀是约束也能塑形；财是掌控也占用心力；比劫是协作也包含竞争。
- 年干与时干可用于比较内在驱动和公开表达，但只有明确生克证据时才讨论反差，不套固定人物故事。

## 七个报告切面

| 切面 | 主要证据 | 输出边界 |
|---|---|---|
| 综合 | 日主、月令、透干藏干、支关系 | 给结构摘要和核验问题，不下宿命定论 |
| 性格与资源 | 印、食伤、官杀、财、比劫及所在柱 | 优势与代价成对出现，落到可行动建议 |
| 事业财运概览 | 财官印食伤比劫组合、月柱与阶段 | 只给概览，不保证职业结果、收入或投资收益 |
| 婚恋概览 | 日支及关系结构 | 只谈互动倾向，不断言必婚、必离或他人行为 |
| 阶段趋势 | 两派起运、大运、目标流年 | 写机会窗口和风险管理，不把流年当事件保证 |
| 流派差异 | 换日、起运及下列三类方法 | 并列依据和差异，不静默选派 |
| 免责声明 | 传统文化定位与现实决策边界 | 必须保留，不用小字弱化 |

## 旺衰、格局与喜用神

这些判断存在方法差异，只能作为模型判读方法，不进入确定性 `core`：

- **旺衰**：并列“月令主导、通根透干”与“全局生克制化、寒暖燥湿”观察。分别列证据，不以元素个数投票。
- **格局**：并列“月令取格、核对透干成败”与“全局做功、制化链条”观察。明确成立和破坏条件。
- **喜用神**：并列扶抑、调候、通关三类目标。三者可能给出不同用神，必须解释各自解决什么问题，不合并成一个唯一答案。

若资料不足以完成其中任一方法，就明确标为“该方法证据不足”，继续呈现其余方法。

## 阶段与流派呈现

`calculation.四柱结果.另一派` 用于判断 23:00 子时换日与 00:00 子夜换日是否产生差异；即使本例相同，也说明已核对。日柱不同时，`alternateCalculation` 是脚本以另一 `dayBoundary` 再次调用 core 得到的完整命盘，两套日主、十神、关系、大运和流年分别引用，不得从摘要补算或跨派拼接。每套命盘内的 `起运大运.起运流派` 又同时含时辰折算法与分钟折算法，两者也必须保留。阶段分析先引用起止年份，再引用运柱与目标流年。

## 表达与安全

把结论写成可检验假设，例如“在高规则环境中可能更容易形成稳定输出，可回看……”，不要写成“你必然……”。每项建议落到现实行动、信息收集或风险控制。

本报告用于中国传统术数的文化研究与娱乐。健康内容不构成医疗诊断；身体不适应就医。事业财运内容不构成投资、职业、法律或收益保证；重大决定应基于现实资料并咨询相应专业人员。
