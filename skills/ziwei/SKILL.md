# 紫微斗数命盘

## 核心原则

本技能把紫微斗数作为传统文化研究与娱乐性分析工具。确定性的公历/真太阳时/农历转换由仓库历法内核完成，命宫、身宫、五行局、紫微天府、十四主星、四化和大限由 `core/ziwei` 计算；模型不得心算、改写星曜或用单星替用户断言现实事件。

## 执行流程

1. 一次性收集公历出生日期、出生地民用时间、经度、出生当日 UTC 时区偏移（或标准经线）和性别；不要猜测历史时区、夏令时、出生时间或出生地点。
2. 调用本技能目录下 `scripts/calculate.js`（其内部调用 `lib/analyze.js`），或者在仓库根目录执行：

```bash
node - <<'NODE'
const { analyze } = require('./skills/ziwei/lib/analyze');
console.log(JSON.stringify(analyze({
  birthDate: '1990-01-01',
  birthTime: '12:00',
  longitude: 121.47,
  utcOffsetMinutes: 480,
  gender: 'male',
}), null, 2));
NODE
```

3. 返回 `needs_input` 时，按 `missing` 和 `questions` 一次性补齐资料并停止判读。
4. 返回 `ready` 时，只引用 `supplement.calculation` 中的宫位、星曜、四化和大限；报告按“算出 → 依据 → 可供判读 → 行动 → 边界”展开。
5. 明确披露采用的换日、真太阳时、闰月和四化口径。不同流派结论不静默择一；资料不足时写“不足以判断”。

## 能力范围

- 命宫、身宫与十二宫落支
- 三方四正关系，供报告引用宫位之间的结构证据
- 五行局、紫微/天府安星和十四主星
- 生年四化（禄、权、科、忌）
- 阳男阴女顺行、阴男阳女逆行的大限宫位骨架
- 命宫、夫妻宫、官禄宫和财帛宫的结构化信号，供现实核验

当前不覆盖：完整辅星亮度、流月流日精批、飞星飞限、宿主图片识盘和任何保证性预测。

## 路由边界

- 只有出生资料、未明确紫微体系时，综合问题可转 `bazi`；明确点名紫微斗数时使用本技能。
- 明确婚恋或事业财运的深度需求，紫微结果只作补充，并转 `love-marriage` 或 `wealth-career`。
- 六十四卦、梅花易数、六爻或奇门局盘不在本技能内；住宅风水和面相仍按对应技能边界处理。

## 安全边界

不得断言必婚、必离、出轨、疾病、寿命、灾祸、确定收益、职位或他人隐私事实。结论只能写成可由用户核验的倾向与问题，不替代医疗、投资、职业、法律或关系决策。
