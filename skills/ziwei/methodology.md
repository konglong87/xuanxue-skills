# 紫微斗数计算口径

## 分层

出生资料校验 → `core/calendar` 民用时间和真太阳时原语 → 完整日期换日 → 公历转农历 → 年界/时支 → `core/ziwei` 命身十二宫、五行局、十四主星、四化、三方四正、大限 → `skills/ziwei` 标准报告。

不调用八字整盘，不计算无关八字大运/目标流年。core 不依赖 skills。直接使用 `ziweiChart` 时，调用方须提供已归一化农历资料；它不声称校验真实出生日期或闰月存在性，出生资料应使用 `birthChart`。

## 时间策略

- `useTrueSolar` 默认 true：复用当前仓库均时差近似和经度校正，非天文观测精密计时。历史UTC偏移由调用方确认。
- `dayBoundary` 默认 `23:00`，另支持 `00:00`。23点换日时先移动整个公历日期，再转农历，因此月末、闰月末和年末一起进位。
- `yearBoundary` 默认 `lunar-new-year`，由所采用农历日期定年。另支持 `lichun`：使用真实出生瞬间，先将民用墙钟转换到节气表的UTC+8时钟；不以真太阳时偏移改变物理瞬间。
- `leapMonthPolicy` 仅支持 `same-month`，闰月仍按原月数安宫。不实现前后半月分拆或进月流派。
- `transformationPolicy` 仅支持 `traditional` 固定年干表；其他表尚未实现。
- 年界×日界四种组合均生成完整盘并校验；未实施的闰月、四化、亮度等流派不能由模型补齐。

## 安宫与安星

- 十二宫坐标寅起；时辰偏移子起。这两种索引必须分开。
- 命宫：寅起正月，顺数生月，逆数生时。身宫：改为顺数生时。
- 五行局按命宫干支定局，宫内天干必须与命宫元数据一致。
- 以农历日、五行局安紫微天府，按星系相对位置安十四主星。
- 四化涉及的文昌、文曲、左辅、右弼也实际安星；四个四化必须各有唯一落点。
- 三方四正记录宫位关系，不把结构直接等同现实事件。
- 大限以局数起虚岁，每十年一宫；阳男阴女顺行，阴男阳女逆行。本版仅给骨架，不提供精确起限日期或应期预测。

## 验证与边界

`verification` 检查宫位、天干、主星、四化、关系和大限结构完整性；不等于独立准确性证明。独立黄金测试只验证同口径计算，不证明传统解释可预测人生。

报告从共享安全模块取得边界，证据不足写“不足以判断”。不根据命盘作疾病、寿命、灾祸、收益、婚姻或第三方行为的确定断言。
