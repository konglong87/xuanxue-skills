# 紫微斗数方法口径

本文件只声明本仓库实现的计算边界，不把任一流派包装成唯一真相。

## 计算链

`公历出生资料 → 民用时间/真太阳时 → 四柱内核获取生年干支与时支 → 农历年月日（闰月按同月口径） → 命宫/身宫 → 五行局 → 紫微天府与十四主星 → 三方四正 → 四化 → 大限宫位骨架`

## 结构化证据

- 命宫：寅起正月，顺数生月，逆数生时。
- 身宫：寅起正月，顺数生月，顺数生时。
- 五行局：由命宫天干地支取数定木三、金四、水二、火六或土五局。
- 主星：以农历日和五行局安紫微、天府，再按固定星系相对位置安十四主星。
- 三方四正：每宫保留三方、对宫和四正的地支关系，供下游引用，不直接把关系升级为现实断语。
- 四化：以生年天干映射禄、权、科、忌；映射表作为版本化常量暴露，便于未来增加流派配置。
- 大限：以五行局起始虚岁，每十年一宫；顺逆由生年干阴阳与性别决定。

## 不做的事

不根据星曜直接写疾病、寿命、灾祸、确定婚姻结果、投资收益或他人事实；不从缺失出生资料推算；不把结构化排盘当作现实证据。
