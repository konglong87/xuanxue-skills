## 零 · 底层哲学（贯穿所有体系，写进各 skill 的 methodology）

**核心链条**：`意 → 象 → 符 → 行`

> 意（意识）产生象（形象），象提取符（符号），符指导行（行动）。

- 口诀「**意识即形象**」在 R1 中被 玄学解法 / 风水 / 手诀 / 婚恋 / 玄学逻辑 五类共同引用，是全体系的第一原理。
- 相法对应口诀：「**相由心生**」。
- 箴言：「苟以行言，占吉凶」—— 符号若不转化为具体行动与社会价值，皆为虚妄。
- 玄学基础层：十天干 / 十二地支 / 八卦的**万物类象**（如甲为…），用于把符号锁定到现实物品。这是「造相」与「灭相」的前提。

**实现含义**：每个 skill 的输出都必须落到「行」—— 只给判断不给动作的报告不合格。

## 二 · 风水·纳气法（R2、R3、R7）⭐ 本体系最硬核、最可代码化的部分

### 2.1 罗盘被否决（这是路线级结论，不是补充意见）

**三条失效理由**

| # | 理由 | 量级 |
|---|---|---|
| 1 | **地磁偏角** —— 罗盘指地磁北极而非天文北极，磁极无规律偏移 | 20 年误差可达 **2°**，而风水中 **1° 之差即天壤之别** |
| 2 | **地磁近日变化** —— 受太阳风压制 | 同一点位**早晚测量结果完全不同** |
| 3 | **环境干扰** —— 钢筋混凝土、手机、家电 | 误差可达 **10° 以上** |

**历史案例（可作验收用例）**：公元 1407 年明长陵，廖增等顶尖风水师联合测算为「癸山丁向」（北偏东约 15°），而**实际物理方向是北偏东 6°** —— 皇陵风水从第一天就被罗盘坑了。

**正确测法（卫星地图法）**
1. 打开具备电子罗盘功能的**卫星地图 APP**
2. 放大至看清**楼宇物理轮廓**
3. 使 APP 自带红线与**建筑边缘平行**，读取真实**天文北极**方位
4. 卫星遥感不受钢筋混凝土与电磁干扰 —— 是汉代「土圭测日影」在数字时代的延续

> **对 `core/` 的直接影响**：原计划的 `declination(city, year)` 磁偏角城市简表**不再是主路径**，因为卫星地图给出的度数已是真北。是否保留为「用户只有罗盘读数」时的备用校正，见开放问题。

### 2.2 纳气四部曲（确定性流程）

| 步 | 操作 | 关键点 |
|---|---|---|
| 1 | **测单元门** | 卫星地图测**一楼单元门**精准度数，**身在门内、面向门外**。⚠️ 决定房子吉凶的核心气口是单元门，**不是自家防盗门** |
| 2 | **标入户门** | 户型图上标出自家大门（入户门）的**朝向箭头** |
| 3 | **平行对齐**（真传核心） | 转动纳气盘，使盘面箭头方向与户型图上入户门方向**完全平行，而非重合** |
| 4 | **定位中心** | 确定房屋「主体中心」。**规则：划定长方形区域时，若扩大的范围中「空缺」多于「实墙」，则停止扩大。** 纳气盘原心对准该中心点 |

### 2.3 格局判定：气位 / 水位（**2044 年前适用**）

| 区 | 九宫数 | 方位 | 性质 | 应设置 |
|:--:|---|---|---|---|
| 🔴 **气位**（纳气位） | **6, 7, 8, 9** | **西北、正西、东北、正南** | 「风」的源头，自 1964 年以来相对稳定 | 门、窗、**灶**、**床**、书桌 |
| 🔵 **水位**（下水位） | **1, 2, 3, 4** | **正北、西南、正东、东南** | 「水」的出口 | 厕所、马桶、水槽、洗衣机 |

**破格判据**（运气不佳的物理根源）
- 马桶在红区 → **破气**
- 床位在蓝区 → **被压制**

> 这是一张**纯查表 + 方位归属**的判定，输入「家具 → 所在方位」即可输出合规/破格清单。属于 `core/` 的确定性计算，必须有测试。

### 2.4 龙虎墙体博弈

**判定方法**：躺在枕头上，看墙壁是否**连贯地绕过床头**。**墙体的中断（通常是门）决定哪一侧是「绕」的一方。**

| 格局 | 判据 | 含义 | 适配 |
|---|---|---|---|
| **龙绕** | 左墙连贯 | 传统、稳定、大家长说了算；正财 | 守业者、依附名牌老字号 |
| **虎绕** | 右墙连贯 | 创新、冒险、女性或花钱方更有话语权；偏财 | 创业者、变革者、网红爆款 |

**青少年卧室修正案**
- 龙逼压（左侧紧贴高柜或墙）→ 性格压抑，**抑郁倾向**
- 虎逼压（右侧紧迫）→ **叛逆**
- 化解：**换头睡** —— 改变身体对空间向量的感知，迅速调节心理压力

**选址适配**：龙强虎弱 → 依附平台惯性稳健发展 ｜ 虎强龙弱 → 靠个人特质暴力破局

### 2.5 厨房水灶

| 布局 | 判据 | 结论 |
|---|---|---|
| **水火相刑** | 水槽与灶台呈 **90° 垂直** | **大忌** → 本钱流失、家人争执、决策焦虑、现金流无端流失。**化解：错开摆放，避免水火直冲** |
| **收虎水** | 水槽在**右侧（虎位）**且与灶台**同线** | 最利捕捉风险中的偏财，投机与创新型业务的**顶级配置** |

### 2.6 明堂与「凡尔赛陷阱」

原则：**明堂在前，靠山在后**。

**反例：凡尔赛宫**。路易十四严守了「左高右低」，却犯致命错误 —— **明堂后置、背后无靠**（最壮丽景观与放射状广场放在建筑正后方）：
1. **人丁稀落** —— 背后空虚缺乏支撑，难以家族传承
2. **虚无享乐** —— 明堂在后意味过度追求感官享受，瓦解严肃进取精神

**现代判据**：阳台（主景观位）方向与楼门朝向**正好相反** = 陷入凡尔赛陷阱 → 沉溺消费享乐，事业传承与家庭凝聚力无力。

**明堂宽阔**：视野的物理深度直接对应思维广度。水系（湖泊/喷泉）是「人心的按摩师」，对冲职业倦怠、调节财富聚集。

「男左女右」被判定为**历史惯性形成的性别偏见**。新逻辑：

## 四 · 奇门遁甲（R3、R4、R5）

定位：**二元对抗下的致胜 OS**，不是算命。SSR 级；**安全度 0**（改变必然产生蝴蝶效应），新手严禁乱动。

### 4.1 六害与灭相

**六害**：击刑、入墓、庚、虎、门破、空亡。

**灭相（Clear Phase）**：在**现实方位的对应点**，撤掉与符号意象匹配的物体。
> 示例：正东「戊」击刑 → 必须撤掉东方厚重的**棕黄色容器或钱罐**。

### 4.2 入局仪式（R3）

1. **道德前提**：立我利他。无大事者、心乱者、存害人之心者，**严禁起局**
2. **开局**：面向北极（北斗），致敬先贤
3. **封局咒（16 字）**：「所有符号，听我号令；世间万象，助我性命」
4. **九字真言**：「临、兵、斗、者、皆、阵、列、前、行」

### 4.3 财富七要害（R4）

| 要素 | 战略定义 | 职场映射与判据 |
|---|---|---|
| **戊** | 本钱 / 根本性资产 | 薪资、存款、房产。**戊击刑 → 本金亏损或裁员减薪风险** |
| **生门** | 利润 / 增值扩张 | 资本回报率与盈利能力。**受损 → 高投入、低产出** |
| **六合** | 合伙 / 资源纽带 | 融资渠道、上下游供应链、职场中介与人际网 |
| **月令** | 天时 / 宏观性价比 | 决定成功成本。**月令生助 → 「一换一百」红利期；月令克制 → 须建立「艰苦斗争」预期，通过反抗压迫争取利润，否则更换赛道** |
| **行业** | 路径适配性 | 见 4.5 行业取象表 |
| **实干** | 机会 / 平台与需求 | 识别市场需求的能力 + 承载才干的支撑平台 |
| **干财** | 控制力 | 日干财 / 生年财 —— 对可调动资源的实际控制深度 |

**卡点处置**：戊击刑或生门入墓 → 资产减值防御战 → 战略从「扩张」转「对冲」；戊不稳时**严禁任何投机性资产投入**，优先确保现金流。

### C1 纳气盘对齐：「平行」还是「叠合」？（三份资料 2:1）

### C2 气位/水位与三元九运的关系
