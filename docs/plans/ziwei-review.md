# 紫微修复：架构、实施和验收计划

目标：修复初版排盘、输入口径和升级缺陷，测试正确值而非仅测试结构。

## 架构
- 通用对象工具下沉 core/_shared，skills 保留兼容导出；core 不反向依赖 skills。
- core/ziwei 分离规则常量、输入策略、历法适配、命盘结构校验；只复用历法原语，不计算无关八字大运/目标流年。
- 宫位索引用寅起序；时辰索引用子起序。两种坐标不得混用。
- 显式定义年界、日界、闰月、时间和四化口径；提供已支持年界/日界的完整对照盘，不宣传未实现的流派。
- 安装manifest按已知版本技能清单验证，保留所有权和路径约束。

## 实施
1. 写出正月子时、各宫天干、四化落点、晚子跨月跨年失败回归。
2. 修复安宫传参/坐标，补齐四化涉及的昌曲辅弼，加入输出一致性门禁。
3. 替换八字整盘依赖为独立紫微历法适配，严格验证CLI与库选项。
4. 并行修复旧版升级；更正历史宿主验收声明；发布补丁版本。

## 验收
- 全量Jest、独立固定版本外部计算器交叉校验（同口径、生成数值fixture，不引入运行时依赖）。
- 任意cwd、不同TZ、缺失/恶意输入、真实安装升级验证和卸载。
- 将真实CLI结果渲染成命盘验收图，截图检查；不将截图当作算法正确性的替代。
- 更新公开文件哈希；清理仅本轮创建的临时文件；通过后commit/push origin main。

## 闭环结果

已按本方案执行，复现缺陷均已修复。Node18主工作区和Node22公开归档各59 suites/966 tests通过，E2E各68/68；详见 `docs/ZIWEI-REVIEW.md`。截图仅验证真实CLI可见输出，未升级为宿主调用证据。
