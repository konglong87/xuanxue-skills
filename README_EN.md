# xuanxue-skills

[中文](README.md) | Current version `v0.1.0` | [MIT License](LICENSE)

> Add Bazi, relationships, career and wealth, palm reading, and external Qimen chart reading to your AI agent.

You do not need to know skill names or metaphysics terminology. Install the project, then ask questions in everyday language.

## Start in 30 seconds

In WorkBuddy, Codex, Claude Code, Cursor, or Trae, say:

```text
Please install https://github.com/konglong87/xuanxue-skills
```

After installation, say:

```text
Please verify that xuanxue-skills is installed and tell me which capabilities are available.
```

If the current agent can run terminal commands, it can read this repository's instructions and complete the installation. Otherwise, use the [manual installation](#manual-install) below.

## What you can ask

Copy one of these prompts and replace the details with your own.

| What you want | Example request | What to prepare |

| General Bazi | `Analyze my complete birth chart and show where major schools disagree.` | Birth date, time, place, and gender |

| Career and wealth | `Analyze my career direction, work patterns, and wealth cycles without promising returns.` | Complete birth data and your question |

| Qimen chart | `Read this Qimen chart and explain the evidence palace by palace.` | A chart generated by a trusted external app |

Complete Bazi example:

```text
Please analyze my complete birth chart.
Birth date: 1990-01-01
Birth time: 12:00
Birthplace: Shanghai
Gender: male
Focus: personality, relationships, career and wealth, and trends for 2026
Show the different schools for day boundary, luck-cycle start, strength, and structure.
Do not silently choose one school for me.
```

If required information is missing, the skill asks for it together instead of guessing your birth time or location.

## What to prepare

| Scenario | Best input |
|---|---|
| Bazi, relationships, career and wealth | Gregorian birth date, accurate birth time, birth city, and gender; add the historical time zone for overseas or historical records when possible |
| Palm reading | Separate photos of both hands, palms up, natural light, sharp focus, no beauty filter, and no covered lines |
| Qimen | A complete chart screenshot from a trusted app, or a palace-by-palace transcription; this release does not generate charts |

## More than prompts

- **Code-backed calculation**: pillars, solar terms, true solar time, luck cycles, and stem-branch relations come from a shared calculation engine instead of model mental math.
- **Schools in parallel**: disagreements about day boundaries, luck-cycle starts, strength, structures, and useful elements remain visible with methods and evidence.
- **Reality checks**: readings are framed as tendencies and questions you can check against reality, not invented life events.
- **Safety boundaries**: no return guarantees, inevitable marriage or divorce claims, or medical diagnosis; cultural interpretations are not presented as certain facts.

## Important boundaries

- This project is for traditional Chinese cultural research and entertainment. It is not medical, investment, career, legal, or other professional advice.
- Birth data, palm photos, and charts are handled by the host agent you choose. This project does not upload or persist them, but the host platform's data policy still applies.
- Public-figure fixtures verify chart calculation only. They do not prove that metaphysics can predict life events.
- Health-related palm observations may describe constitution or energy tendencies only and are not medical diagnoses.

## For technical users

### Manual install

Node.js 18 or newer is required. This example installs for a Codex user account:

```bash
npx --yes github:konglong87/xuanxue-skills install --agent codex --scope user
npx --yes github:konglong87/xuanxue-skills verify --agent codex --scope user
```

Replace `codex` with `claude-code`, `cursor`, `trae`, or `workbuddy`. Use `--scope user` for your user environment, or run from the target project with `--scope project`.

The installer copies the complete `core/`, `vendor/`, and `skills/` runtime to a stable versioned directory, then creates host discovery entries. Generic leaf-skill installers omit the shared calculation engine and are not suitable for this project.

Safe uninstall:

```bash
npx --yes github:konglong87/xuanxue-skills uninstall --agent codex --scope user
```

The uninstaller removes only entries still owned by this project. Retargeted paths and unrelated skills are preserved.

### Agent compatibility

`verified` means host discovery and a real invocation were completed. `experimental` means the installer was tested but host evidence remains incomplete. See [agent-compatibility.json](docs/agent-compatibility.json) for the evidence record.

| Agent | Status | Current evidence |
|---|---|---|
| `claude-code` | `verified` | All five skills were discovered; Bazi, relationships, career and wealth, and dual-domain routing passed real-model acceptance |
| `codex` | `experimental` | Official paths and installer probes pass; the test machine's CLI exited abnormally before host discovery |
| `cursor` | `experimental` | Installer lifecycle and runtime probe pass; real discovery was blocked by the test machine's authentication state |
| `trae` | `experimental` | Path mapping and installer lifecycle pass; no Trae host was available on the test machine |
| `workbuddy` | `experimental` | Skill directory and import logic were confirmed; real host discovery and invocation remain pending |

### Architecture and verification

```text
core/ganzhi <- core/calendar <- skills/bazi
                                <- skills/love-marriage
                                <- skills/wealth-career

core/direction <- core/naqi
core/ganzhi + core/direction <- skills/qimen
host vision -> skills/palm contract
```

`core/` never depends on skills. All five hosts share one calculation engine and runtime. Runtime dependencies are vendored; `lunar-javascript` retains its MIT license and provenance.

Development verification:

```bash
npm install
npm test -- --runInBand
node scripts/e2e-smoke.js
```

See [test cases](docs/TEST-CASES.md) for reproducible fixtures and historical time-zone rules, the [roadmap](docs/ROADMAP.md) for future work, and [CLAUDE.md](CLAUDE.md) for architecture constraints. Source material is third-party lineage teaching and is not distributed with this repository; the scope of each rule is stated in the owning skill's `methodology.md`.
