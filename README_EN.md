# xuanxue-skills

[中文](README.md) | Current version `v0.1.0`

Traditional Chinese metaphysics skills for Claude Code, Codex, Cursor, Trae, and WorkBuddy. A shared code engine handles deterministic calculations; the host agent handles interpretation, reality checks, and bounded language.

## More than prompts

- **Code-backed calculation**: pillars, solar terms, true solar time, luck cycles, stem-branch relations, and direction rules must come from `core/`.
- **Schools in parallel**: disagreements about day boundaries, luck-cycle starts, strength, structures, and useful elements remain visible with their methods and evidence.
- **Reality checks**: readings are framed as hypotheses the user can check, never as fabricated facts about a life or another person.
- **Safety boundaries**: no return guarantees, inevitable marriage/divorce claims, or medical diagnosis; image observation and deterministic computation have separate contracts.

## Capabilities

| Capability | Status | Input and boundary |
|---|---|---|
| `bazi` | Available | Complete birth date/time, longitude, historical UTC offset, and gender; code-calculated chart with parallel schools |
| `love-marriage` | Available | Complete birth data plus a relationship question; no inevitable marriage/divorce or unverified claims about others |
| `wealth-career` | Available | Complete birth data plus a career/wealth question; no return guarantees or replacement for career/investment advice |
| `palm` | Available | Clear photos of both open palms; host vision observes, code validates evidence and safe output |
| `qimen` | Available | A trusted chart already generated by an external app; validates and reads it, but does not generate a chart |
| `face-reading` | Planned, unavailable | **Not available due to facial-image privacy concerns.** |
| `fengshui-naqi` | Future | Some deterministic direction/naqi primitives exist; the user skill is blocked by C1/C2 decisions |
| `divination` | Future | Not implemented and absent from the current release manifest |

Users describe the goal rather than memorizing skill names. A broad birth-data reading routes to `bazi`; relationship and career questions route to their domain skills; palm photos route to `palm`; an external Qimen chart routes to `qimen`.

## Install

### Easiest: ask your agent

In WorkBuddy, Codex, Claude Code, Cursor, or Trae, say:

```text
Please install https://github.com/konglong87/xuanxue-skills
```

If the current agent can run terminal commands, it can read this repository's instructions and complete the installation. Ask it to run `verify` afterward. If it cannot run terminal commands, use the manual commands below.

### Manual install

Node.js 18 or newer is required. The portable path is the project's own GitHub-backed npx installer:

```bash
npx --yes github:konglong87/xuanxue-skills install --agent codex --scope user
npx --yes github:konglong87/xuanxue-skills verify --agent codex --scope user
```

Replace `codex` with `claude-code`, `cursor`, `trae`, or `workbuddy`. Use `--scope project` while inside the target project for a project-scoped install.

The installer copies the complete `core/`, `vendor/`, and `skills/` runtime to a stable versioned directory, then creates five host discovery links. Those links never point into the temporary npx cache. Generic leaf-skill installers omit the shared runtime and are therefore not a supported installation path for this project.

Safe uninstall:

```bash
npx --yes github:konglong87/xuanxue-skills uninstall --agent codex --scope user
```

Only links still owned by this project's manifest are removed. Retargeted paths and unrelated skills are preserved.

Claude Code users can also use its marketplace:

```bash
claude plugin marketplace add konglong87/xuanxue-skills
claude plugin install xuanxue-skills@xuanxue-skills
```

For local Claude plugin development, cloning alone is not installation:

```bash
git clone https://github.com/konglong87/xuanxue-skills.git
claude --plugin-dir /absolute/path/to/xuanxue-skills
```

## Example

After install and `verify`, ask the host directly:

```text
Analyze this birth data and show the different schools for day boundary, luck-cycle start,
strength, and structure: 1990-01-01 12:00, Shanghai, male, target year 2026.
```

When required birth fields are missing, the skill asks for all missing fields once and stops. It does not guess historical time zones, longitude, or birth time.

## Architecture and evidence

```text
core/ganzhi <- core/calendar <- skills/bazi
                                <- skills/love-marriage
                                <- skills/wealth-career

core/direction <- core/naqi
core/ganzhi + core/direction <- skills/qimen
host vision -> skills/palm contract
```

`core/` never depends on skills. All five hosts share one `core/`, `vendor/`, and `skills/` runtime. Runtime dependencies are vendored; `lunar-javascript` retains its MIT license and provenance.

Reproducible chart fixtures include public birth records for Barack Obama, Steve Jobs, and Albert Einstein. See [test cases](docs/TEST-CASES.md) for historical time-zone and oracle details, and [references](docs/REFERENCES.md) for rule sources. These fixtures test deterministic charts, not claims about life events.

```bash
npm install
npm test -- --runInBand
node scripts/e2e-smoke.js
```

See the [roadmap](docs/ROADMAP.md) and [architecture rules](CLAUDE.md). Contributions with reproducible fixtures, sourced rules, host acceptance evidence, or safety fixes are welcome.
